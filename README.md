# Церковнославянский язык для Minecraft

Ресурспак для Minecraft Java 26.3, который добавляет в игру церковнославянский
язык. Переведено всё — 8559 строк: меню, настройки, предметы, существа,
достижения, сообщения о смерти, подписи звуков, команды, Realms. Под перевод
нарисован свой пиксельный шрифт с ударениями, звательцами и титлами.

<img src="публикация/снимки/04%20В%20мире.png" width="800">

## Установка

1. Скачай zip из [Releases](../../releases) и положи его в папку
   `.minecraft/resourcepacks`, не распаковывая.
2. В игре: **Настройки → Пакеты ресурсов** — перенеси пак вправо.
3. **Настройки → Язык** — выбери «Церковнославѧ́нскїй (Рѡссі́йскїй и҆зво́дъ)».
   Он стоит сразу перед русским.

Шрифт включается только в этом языке. Русский язык, ники игроков, чат и
таблички остаются обычными буквами.

Пак рассчитан на версию 26.3. На других версиях часть строк останется
по-английски.

## Как переведено

Орфография синодальная — как в нынешних богослужебных книгах: оксия, вария
и камора, звательце над начальной гласной, ѿ, ѡ, ѻ, ꙋ, ѧ, ꙗ, ѣ, ї, ер на конце
слова, вопрос через точку с запятой. Подробно — в [ПРАВИЛА.md](ПРАВИЛА.md).

Несколько решений, о которых лучше знать заранее:

- Существа названы церковнославянскими словами, а не транслитом. Крипер —
  га́дъ (так в Быт. 1:24 названы ползучие твари), эндермен — краѧ́нинъ, гаст —
  рыда́тель, иссушитель — и҆зсꙋши́тель, зомби — мертве́цъ.
- Незер — а҆́дъ, вредина — бѣ́съ, дракон Края — ѕмі́й кра́ѧ.
- Магия названа так, как её называет Писание: зачарование — ѡ҆баѧ́нїе,
  ведьма — волше́бница, заклинатель — чародѣ́й.
- Священные слова на игровое не переносятся: под титлом в игре ничего нет,
  возрождение — не «воскресение», а возникнове́нїе.
- Прошедшее время передано аористом: «%1$s падѐ съ лѣ́ствицы». Аорист не
  различает род, поэтому из сообщений не видно, кто играет — он или она.
- Уровни чар и зелий записаны славянскими цифрами: а҃, в҃, г҃…

Все названия предметов, существ, чар и местностей — в [ТЕРМИНЫ.md](ТЕРМИНЫ.md).
Короткий словарик чар и зелий, чтобы понимать, что за книга у тебя в руках, —
в [публикация/Словарик.md](публикация/Словарик.md).

## На чём проверено

- Иеромонах Алипий (Гаманович). Грамматика церковно-славянского языка.
- И. В. Плетнёва, А. Г. Кравецкий. Церковнославянский язык.
- [hunspell-cu](https://github.com/slavonic/hunspell-cu) — словарь форм
  с ударениями от Slavonic Computing Initiative.
- Елизаветинская Библия в Юникоде из проекта
  [Ponomar](https://github.com/typiconman/ponomar).

Перевод делался с помощью нейросети. Спорные слова, решения о лексике и вид
шрифта — мои. Каждая строка проходит автоматическую проверку: подстановки,
допустимые буквы, ударения, звательца, ер на конце. Каждое слово сверяется
с корпусом богослужебных текстов, около 190 тысяч форм. Если форма с корпусом
расходится, это видно сразу.

## Нашёл ошибку

Открой [issue](../../issues) и напиши, как строка выглядит в игре и как
правильно. Если знаешь ключ строки (например, `block.minecraft.oak_log`),
будет ещё проще.

## Сборка из исходников

Нужен Python 3.10+ с Pillow и установленный Minecraft 26.3.

```
pip install pillow
python инструменты/исходники.py
git clone --depth 1 https://github.com/slavonic/hunspell-cu корпус/hunspell-cu
git clone --depth 1 --filter=blob:none --sparse https://github.com/typiconman/ponomar корпус/ponomar
git -C корпус/ponomar sparse-checkout set Ponomar/languages/cu/bible
python инструменты/проверка.py
python инструменты/сборка.py
```

Готовый пак появится в папке `сборка/`.

- `перевод/*.json` — сам перевод в обычном Юникоде.
- `шрифт/буквы.txt`, `шрифт/знаки.txt` — буквы и надстрочные знаки, нарисованные
  клетками.
- `инструменты/словарь.py слово` — показывает формы слова из корпуса
  с ударениями.
- `инструменты/проверка.py --всё --корпус` — проверяет перевод.
- `инструменты/сборка.py` — собирает пак.

Игра не умеет ставить знак над буквой. Поэтому сборка превращает каждую букву
вместе с её знаками в отдельный готовый символ частной области Юникода.
По этой же причине шрифт и действует только в этом языке.
